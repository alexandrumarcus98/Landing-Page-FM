## Getting Started

First, run the `server` strapi:

```bash
cd server
npm i
npm run dev
```

Open [http://localhost:1337/admin](http://localhost:1337/admin) with your browser to see strapi server.

Second, run the client `web`:

```bash
cd web/
pnpm i
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to web client.
